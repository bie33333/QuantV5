# LimitUp_Factor_Model v2.0 · A股涨停接力量化策略

依据 `chat.md`（策略定义书）+ **经典知行风控参数集**实现的事件驱动回测引擎 + Web 可视化看板。
策略：**只在市场允许打板时（等权指数>MA20 且 连板晋级率≥30%），参与最强题材的核心个股，竞价确认、成交可及才下单**；
出场按经典三级：硬止损 5% / 右侧移动止盈（浮盈≥15% 后自峰值回撤 6%）/ 时间强平（≤15 交易日），并带账户回撤熔断（≥12% 清仓空仓）。

## 快速开始

```bash
# 1. 安装依赖（numpy/pandas/pyyaml 必需；tushare 仅真实数据需要）
pip install -r requirements.txt

# 2. 回测（默认 synthetic 合成数据，全流程端到端可跑）
python scripts/run_backtest.py                     # 完整 v2 模型 + 分层消融 A/B/C/D
python scripts/run_backtest.py --walk-forward      # 增加样本外滚动验证
python scripts/run_backtest.py --help

# 3. 生成可视化看板（读取 outputs/result.json）
python scripts/build_dashboard.py
# → outputs/dashboard.html（单文件，直接浏览器打开）
```

### Tushare 真实数据

```bash
export TUSHARE_TOKEN=你的token          # 或写入 config/model_v2.yaml → data.tushare.token
python scripts/run_backtest.py --source tushare --start 2024-01-01 --end 2026-06-30
```

- 首次运行按交易日批量拉取全市场 `daily` / `daily_basic`，落盘缓存于 `.data_cache/`，可断点续传。
- **数据口径提醒**：日线能准确识别 涨停/一字/触板/连板；**首封时间、炸板次数、封单额、龙虎榜、9:25竞价量** 等高频字段普通 Tushare 权限拿不到 → 对应因子按中性/估计处理（`estimate`），成交概率用日线代理模型，非 Level-2 排队深度。
- token 缺失或拉取失败时自动回退 synthetic。

## 系统架构（规格书五层 + 执行/退出）

```
数据层 ──→ ①市场情绪层(8因子→0~100，看板/诊断用) 
        ──→ 市场硬闸门: 等权指数>MA20(弱市空仓) 且 连板晋级率≥30%
        ──→ ②板块强度层(≥50) ──→ ③个股评分层(≥70,龙头优先) ──→ ④竞价层(9:25, <−3%否决)
        ──→ 成交模拟(一字/排板概率, <30%否决) ──→ 仓位(单票≤40%/≤2只/题材≤80%)
        ──→ 退出(硬止损5% / 右侧移动止盈15%-6% / 持有≤15日) + 组合熔断(权益回撤≥12%清仓空仓)
```

| 模块 | 说明 |
| --- | --- |
| `luv2/sources.py` | 数据源：`SyntheticSource`（全字段合成，可靠级 SIM）/ `TushareSource`（真实日线，高频字段估计） |
| `luv2/detectors.py` | 动态涨跌停价（主板10%/创业科创20%/ST分档、2026-07 上交所 ST 新规参数化）、一字板/触板、连板数、市场原始指标 |
| `luv2/engines/market.py` | 8 因子自适应百分位 → 情绪 0~100 → 状态(VERY_STRONG..FROZEN) |
| `luv2/engines/theme.py` | 8 因子截面排名 + 5 日持续性加权（防一日游） |
| `luv2/engines/stock.py` | 市场地位20/板块15/连板10/换手10/量价8/封板8/次日溢价7/资金5/市值2（85 分制盘前模型） |
| `luv2/engines/auction.py` | 竞价 0~15 分（9:25 追加），近一字/过热/低开分别处理 |
| `luv2/execution.py` | 成本（佣金/印花税/滑点）+ 成交概率 + 部分成交 |
| `luv2/strategy_rules.py` | 动态仓位、信号分级 A/B/C、经典三级出场（止损/移动止盈/时间强平，日线可成交近似） |
| `luv2/backtest.py` | 事件驱动主循环（候选形成→竞价→撮合→出场→熔断→记账），严格数据边界 |
| `luv2/walk_forward.py` | 分层消融 A/B/C/D + 滚动样本外验证 |
| `config/model_v2.yaml` | **唯一事实源**：全部权重/阈值/成本/仓位，改参数不改代码 |

## 已实现 vs 规格书的差异（诚实披露）

1. **数据粒度**：规格书要求 1 分钟线 + 涨停事件 + 封单盘口 + 龙虎榜 + 竞价。当前对真实数据只有日线 → 高频字段缺失/估计，`board_quality`、`money_flow` 等因子中性化；合成源含全字段用于验证引擎路径。模块边界已预留分钟/L2 升级位。
2. **成交模拟**：无 Level-2 排队深度，用 一字板(≤12%)/换手板(55%基准)+竞价修正 的日线代理概率；`Execution Rate / Partial / Missed` 均如实统计，**买不到不记收益**。
3. **退出（经典三级，V3.0 规格口径）**：无分时，日线可成交近似——
   ① 硬止损：当日最低 ≤ 买入价×0.95 → 卖价=min(开盘, 止损价)；② 右侧移动止盈：持仓峰值(含当日最高)≥买入价×1.15 且当日最低 ≤ 峰值×0.94 → 卖价=min(开盘, 峰值×0.94)；③ 时间强平：持有≥15 交易日 → 开盘价卖出。一字跌停封死当日无法卖出、顺延。成交价均为当日真实可达价位（min(开盘,触发价) 在跳空击穿时取开盘，偏保守）。
4. **组合熔断**：账户权益（现金+持仓市值，收盘价计）自峰值回撤 ≥12% → 收盘清仓并空仓，等权指数重新站上 MA20 即解除（同时以清算后权益重置峰值基线）。注：日线粒度下熔断触发与成交价以当日收盘结算，与记账口径自洽（V4 引擎按开盘价强平，属同日近似差异）。
5. **市场硬闸门**：开新仓要求 等权指数代理（全组合收盘价均值）> MA20 且 连板晋级率 ≥30%（取信号日收盘已知数据，无未来函数）。合成数据无真实指数行情，该代理在价格长期上行的合成池中约 85% 交易日放行；真实数据建议接入官方指数（如 510300/000001.SH），引擎已集中到 `luv2/backtest.index_above_ma_map` 便于替换。
6. **阈值**：买入 70 分基线（规格书示例 75 并声明"非神奇数字"），正式阈值建议 `--walk-forward` 网格寻优。
7. **题材**：用 industry（申万/证监会行业）作板块代理，未接概念题材池（可扩展）。
8. 合成数据按自然交易日近似，未对齐真实节假日；情绪/题材基于合成池内的股票集合。

## 风险提示

高风险的短线交易系统。回测 ≠ 未来收益；打板受排队、滑点、撤单、流动性与监管/交易规则变化影响，实盘请独立决策。
